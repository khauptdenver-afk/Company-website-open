HAUPT SYSTEMS — FREE STATIC WEBSITE
==================================

Files: index.html, services.html, about.html, contact.html, style.css, script.js, favicon.svg, CNAME, .nojekyll, robots.txt, sitemap.xml.

This is a handcrafted reconstruction inspired by the Airo screenshots, NOT an export of GoDaddy Airo's original source code or logo. It uses a newly drawn similar-style SVG symbol and does not include Airo proprietary assets.

LOCAL PREVIEW
Unzip and open index.html in your browser. Navigation works locally. Google Fonts require internet; system font fallback is provided.

FREE PUBLISHING ON GITHUB PAGES
1. Create a PUBLIC repository named hauptsystems-site in GitHub. GitHub Pages on GitHub Free generally requires a public repository. Public source code and contact details will be visible.
2. Upload all website files to the root of the repository (including the CNAME file and hidden .nojekyll file).
3. Settings > Pages > Build and deployment: Deploy from a branch, main, /(root), Save.
4. Confirm the temporary GitHub Pages URL loads properly BEFORE changing DNS.
5. For custom domain hauptsystems.com, confirm the domain is set under Settings > Pages. Then configure ONLY the website DNS at GoDaddy following GitHub's CURRENT instructions. Do not change nameservers or email MX, SPF, DKIM, DMARC, or Zoho verification TXT records.
6. Enable Enforce HTTPS after certificate issuance and check all navigation and email links.

IMPORTANT
- Do not publish by uploading to GitHub and switching DNS until the temporary site has been reviewed and is ready.
- Existing GoDaddy Website Builder hosting will be replaced as the public site only when website DNS is changed.
- Contact page uses mailto:contact@hauptsystems.com, no collecting web form. It depends on visitors having an email client.
